od praznog placa do gotovog objekta. Nezvanična demonstracija; svi podaci su preuzeti
sa [zonedpanonka.rs](https://zonedpanonka.rs).

- `index.html` + `stil.css` + `motor.js` — statički sajt, bez build koraka (Vercel: samo Deploy)
- `frejmovi/hi|md/` — niz frejmova za skrol-scrub (jak/srednji uređaj)
- `media/tour-mobile.mp4` — film za telefon (sam se izvrti, pa „Skroluj dalje ↓")
- `media/faza-6.jpg` — finalna vizija (stilizovani master kadar)
- `CLAUDE.md` — zakoni projekta i proizvodni proces (obavezno štivo)

Proizvodnja slika/videa: Higgsfield (nano banana pro + first/last-frame video modeli),
kompletan proces opisan u CLAUDE.md.
